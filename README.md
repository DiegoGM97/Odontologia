# SmileLux · Clínica Dental

Landing page de clínica dental premium, construida al 100% con [Astro](https://astro.build) y Tailwind CSS v4.

## Desarrollo

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
pnpm preview
```

## Instagram

Las publicaciones de demostración se editan en `src/data/site.ts` → `instagramPosts` (imágenes, likes, comentarios y texto).
